나는 지금까지 molecure 오픈소스를 이용하여 리액트 19 버전에서 프로젝트으로 업데이트 했어.
이제 이 목을 기반으로 새로운 프로젝트를 시작하려고 해.

목표는 SQLGate for MySQL의 기능을 웹으로 제공하는 거야.
SQLGate for MySQL은 MySQL 데이터베이스를 관리하고 쿼리를 실행할 수 있는 도구야. 
웹 버전에서는 사용자들이 브라우저를 통해 MySQL 데이터베이스에 접속하고, 쿼리를 작성하고 실행할 수 있도록 하는 것이 목표야.

지금은 목업 UI를 만들고 있어.
목업 UI에서는 사용자들이 데이터베이스에 접속하기 위한 로그인 화면과,쿼리를 작성하고 실행할 수 있는 메인 화면을 포함할 거야.
로그인 화면에서는 사용자들이 MySQL 데이터베이스의 호스트, 포트, 사용자 이름, 비밀번호를 입력할 수 있도록 할 거야.
메인 화면에서는 사용자들이 쿼리를 작성할 수 있는 에디터와, 실행 결과를 보여주는 영역을 포함할 거야.
목업 UI를 완성한 후에는 실제로 MySQL 데이터베이스에 접속하고 쿼리를 실행할 수 있도록 기능을 구현할 거야.
이 프로젝트를 통해 사용자들이 웹 브라우저를 통해 MySQL 데이터베이스를 쉽게 관리하고 쿼리를 실행할 수 있도록 하는 것을 목표로 하고 있어.

# 목업 UI 만들기
## 메인 툴바 만들기
메인 툴바에서는 사용자들이 자주 사용하는 기능들을 빠르게 접근할 수 있도록 버튼들을 배치할 거야. 예를 들어, 새 쿼리 작성, 데이터베이스 연결, 쿼리 실행 등의 버튼을 포함할 수 있어.
## 로그인 화면
로그인 화면에서는 사용자들이 MySQL 데이터베이스에 접속하기 위한 정보를 입력할 수 있도록 해야 해.
## 개체 패널
개체 패널에서는 데이터베이스의 테이블, 뷰, 프로시저 등의 개체들을 보여줄 거야.
## 쿼리 에디터
쿼리 에디터에서는 사용자들이 SQL 쿼리를 작성할 수 있도록 할 거야.
## 실행 결과 영역
실행 결과 영역에서는 사용자가 작성한 쿼리를 실행한 결과를 보여줄 거야.
그리드는 결과를 표 형태로 보여줄 수 있도록 할 거야. 또한, 오류 메시지도 이 영역에서 표시할 수 있도록 할 거야.

## 상태 표시줄
상태 표시줄에서는 현재 데이터베이스 연결 상태, 실행 중인 쿼리의 상태 등을 보여줄 거야.
## 테마 설정
테마 설정에서는 사용자들이 UI의 색상과 스타일을 개인화할 수 있도록 할 거야. 예를 들어, 다크 모드와 라이트 모드를 선택할 수 있도록 할 수 있어.
## 오른쪽 사이드바
오른쪽 사이드바에서는 추가적인 기능들을 제공할 수 있어. 예를 들어, 쿼리 히스토리, 즐겨찾기 쿼리 등을 보여줄 수 있어.

# 탭 그룹의 "탭 최대화"
탭 최대화가 클릭하면 동작하는데 단축키로는 동작하지 않아. 단축키로도 동작하도록 해 줘.
만약 동작하지 않는다면, 단축키 설정이 올바르게 되어 있는지 확인해 보고, 필요하다면 단축키 설정을 수정해 줘.
그리고 로그를 출력해서 단축키가 클릭 이벤트와 연결되어 있는지 확인해 보는 것도 좋을 거야. 만약 단축키가 클릭 이벤트와 연결되어 있지 않다면, 연결해 주는 코드를 추가해 줘.

# 편집기 열기 그룹 선택시
편집기 열기 그룹에서 열려진 파일 목록을 선택하면 편집기로 포커스를 이동하도록 해 줘. 
다음과 같은 상황에서 포커스가 안돼
편집기 탭의 포커스되어 있는 편집기에는 포커스가 껌뻑어지 않아
포커스는 이동이 되는데, 이전에 편집기가 가지고 있던 포커스의 위치가 아니라 맨처음으로 이동하고 있어.
원래 편집기가 가지고 있던 포커스의 위치로 이동하도록 해 줘. 이렇게 하면 사용자가 편집기에서 작업하던 위치로 바로 이동할 수 있어서 편리할 거야.

# 개체 패널에 테이블 목록에 컬럼 정보는 보여주지 않고
테이블 이름만 보여주도록 해 줘. 현재는 테이블 목록에 컬럼 정보도 함께 보여지고 있는 것 같아. 이 부분을 수정해서 테이블 목록에는 테이블 이름만 보여주고, 
컬럼 정보는 테이블을 클릭했을 때 별도의 개체 패널에 보여주도록 해 줘. 이렇게 하면 테이블 목록이 더 깔끔하게 보이고, 사용자가 필요한 정보를 더 쉽게 찾을 수 있을 거야.

# DB 탐색기의 개체 탐색기와 개체 패널 사이에 Splitter 의 이동
DB 탐색기의 개체 탐색기와 개체 패널 사이에 Splitter 위 아래 이동시 예상하지 못한 움직임이 발생합니다.
Splitter 가 마우스의 움직임 보다 늦게 따라오는 것 같아. 이 부분을 수정해서 Splitter가 마우스의 움직임에 더 빠르게 반응하도록 해 줘. 이렇게 하면 Splitter를 이동할 때 더 부드럽고 자연스러운 경험을 제공할 수 있을 거야.
움직임이 자연스럽지아 다시 확인해 봐

DB 탐색기의 개체 탐색기와 개체 패널 사이에 Splitter 위 아래 이동시 예상하지 못한 움직임이 발생합니다.
처음 Splitter를 클릭하고 드래그 하기 전에 위치가 갑자기 위로 올라갑니다. 그리고 드래그하면 제 위치로 이동합니다. 이 부분을 수정해서 Splitter가 처음 클릭할 때 갑자기 위치가 이동하지 않도록 해 줘. 이렇게 하면 Splitter를 이동할 때 더 예측 가능한 경험을 제공할 수 있을 거야.

Good!

# 다이얼로그창 메세지 또는 알람에 한국어로 표현하지 말고
지금 모든 코드에서 한국어로 표현된 부분을 I18n을 적용해서 다국어로 표현해 줘. 현재 다이얼로그창 메세지 또는 알람이 한국어로 표현되고 있는 것 같아. 이 부분을 수정해서 다이얼로그창 메세지 또는 알람에 I18n을 적용해서 영어로 표현하도록 해 줘. 이렇게 하면 더 많은 사용자들이 이해할 수 있도록 도와줄 수 있을 거야.
 
# 개체 탐색이에 트리의 왼쪽 여백이 너무 많아.
개체 탐색기에 트리의 왼쪽 여백이 너무 많은 것 같아. 이 부분을 수정해서 트리의 왼쪽 여백을 줄여 줘. 이렇게 하면 트리가 더 깔끔하게 보이고, 사용자가 더 많은 정보를 한눈에 볼 수 있을 거야.

# 작업 막대의 순서
지금은 작업 막대의 순서가 "DB 탐색기, 탐색기, 검색" 순서로 재정렬해 줘. 
아직 이전과 같아. 다만 사이드 바에 "DB 탐색기" 가 먼저 나오고 있는 건 확인했어. 
작업 막대의 순서 "DB 탐색기"가 "탐색기"보다 먼저 나오도록 순서를 재정렬해 줘. 이렇게 하면 사용자가 더 쉽게 "DB 탐색기"에 접근할 수 있을 거야.
순서는 바뀌었는데, 시작시에 "탐색기"가 선택된 것 처럼 나와, "DB 탐색기"가 선택 되도록 해 줘. 이렇게 하면 사용자가 "DB 탐색기"에 바로 접근할 수 있도록 도와줄 수 있을 거야.
